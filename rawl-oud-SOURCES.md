# Oud SoundFont

Mono oud plucks by hammondman, CC0 1.0. Sources:

- G2: https://freesound.org/people/hammondman/sounds/172682/
- A2: https://freesound.org/people/hammondman/sounds/172683/
- C3: https://freesound.org/people/hammondman/sounds/172684/

The SoundFont normalizes the plucks, fades their ends, and applies measured
pitch corrections of +1, -4, and -5 cents. It adds no tremolo. Each note's
MIDI timing, velocity, and pitch bend controls playback. Program 24 provides
a compatible plucked-string fallback when using the MIDI without this bank.
